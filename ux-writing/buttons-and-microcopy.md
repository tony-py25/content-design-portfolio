# UX Writing & Microcopy Samples

## Overview

UX writing is the practice of creating clear, useful words that guide users through digital products and services.

These samples demonstrate how I approach interface language with a focus on **clarity, simplicity, consistency, and user action**.

---

# 1. Button & Call-to-Action Copy

Good button labels tell users exactly what will happen when they tap or click.

| Less Clear | Improved UX Copy | Why |
|---|---|---|
| Submit | Submit application | Tells the user what is being submitted |
| Continue | Continue to payment | Sets expectations |
| Click here | View dataset | Describes the destination |
| Learn More | View details | More specific and action-oriented |
| Send | Send message | Makes the action clear |
| Register | Create account | Uses familiar language |
| Get Started | Start contributing | Connects the action to the user's goal |

### Principle

**Use action-oriented language that describes the result of the user's action.**

---

# 2. Form Instructions

Forms can become frustrating when users do not understand what information is required.

### Example: Contributor Registration

**Name**

Enter your full name.

**Language**

Select the language or languages you speak fluently.

**Location**

Enter your country and general region.

**Language Experience**

Tell us briefly about your experience with the language.

**Submit**

Create contributor profile

### Content principle

Instructions should appear close to the field they explain and should answer the user's likely question before confusion occurs.

# 3. Error Messages

Error messages should explain what went wrong and, where possible, tell users how to fix it.

### Less useful

> Invalid input.

### Improved

> Enter a valid email address, such as name@example.com.

---

### Less useful

> Error 404.

### Improved

> We couldn't find that page. Return to the homepage or browse our available datasets.

---

### Less useful

> Upload failed.

### Improved

> Your file couldn't be uploaded. Check your internet connection and try again.

### Principle

A useful error message should answer:

**What happened?**

**Why did it happen?**

**What can I do next?**
